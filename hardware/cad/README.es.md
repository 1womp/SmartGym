# Archivos CAD SmartGym

Idioma: [English](README.md) | Espanol

Esta carpeta contiene archivos SolidWorks, STEP y STL usados para mounts, piezas impresas y enclosure del prototipo.

## Buscador Rapido

| Necesidad | Usar |
| --- | --- |
| Montar el encoder draw-wire | `encodermount.STL` |
| Sujetar hardware a la maquina | `gymmachineclamp.STL` |
| Imprimir enclosure de pantalla | `screen7inchbackplate.STL`, `screen7inchcover.STL`, `screen7inchfrontcover.STL` |
| Montar el sensor ToF | `tof_sensor_holder_nuevo_en mm.STL`, `Fastener.stl`, `Target.stl` |
| Editar CAD fuente | archivos `.SLDPRT` o `.step` |

## Lista Completa

| Archivo | Descripcion |
| --- | --- |
| `encodermount.SLDPRT` | Fuente SolidWorks del mount del encoder. |
| `encodermount.STL` | Export imprimible del mount del encoder. |
| `gymmachineclamp.SLDPRT` | Fuente SolidWorks del clamp de maquina. |
| `gymmachineclamp.STL` | Export imprimible del clamp. |
| `machinetube.SLDPRT` | Referencia/modelo del tubo de maquina. |
| `screen7inch.SLDPRT` | Referencia de pantalla de 7 pulgadas. |
| `screen7inchbackplate.STL` | Placa trasera imprimible. |
| `screen7inchcover.STL` | Cover imprimible de pantalla. |
| `screen7inchfrontcover.SLDPRT` | Fuente SolidWorks del frente de pantalla. |
| `screen7inchfrontcover.STL` | Export imprimible del frente. |
| `Target.step` | Fuente STEP de target ToF. |
| `Target.stl` | Export imprimible de target ToF. |
| `Fastener.step` | Fuente STEP del fastener ToF. |
| `Fastener.stl` | Export imprimible del fastener ToF. |
| `tof_sensor_holder_nuevo_en mm.SLDPRT` | Fuente SolidWorks del holder ToF actualizado. |
| `tof_sensor_holder_nuevo_en mm.STL` | Export imprimible del holder ToF actualizado. |

Los `.SLDPRT` y `.step` son editables. Los `.STL` son para slicing e impresion 3D.
